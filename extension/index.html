PolyMod sites

The mod is built into PolyTrack at app-polytrack.kodub.com. Add any other site that runs the game and it starts there too, as the page loads.

    Chrome asks for access to each site when you add it; all ports of that host are covered. Reload a tab that is already open so the mod starts with the page again. A site has to load the real PolyTrack game for the overlay to have anything to attach to.
